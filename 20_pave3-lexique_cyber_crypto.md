# Lexique cyber-crypto

- **Cryptographie** : méthodes mathématiques protégeant confidentialité, intégrité, authenticité et non-répudiation.
- **RSA** : cryptographie à clé publique fondée sur la difficulté de factoriser N=p×q.
- **ECC** : cryptographie sur courbes elliptiques, fondée sur le logarithme discret elliptique.
- **Signature numérique** : preuve d'origine et d'intégrité.
- **Hash / checksum** : empreinte servant à vérifier l'intégrité d'un fichier.
- **Post-quantique** : cryptographie pensée pour résister aux ordinateurs quantiques connus théoriquement.
- **ML-KEM** : FIPS 203, encapsulation de clé post-quantique.
- **ML-DSA** : FIPS 204, signature post-quantique.
- **SLH-DSA** : FIPS 205, signature hash-based.
- **Modèle de menace** : description de ce qu'on protège, contre qui et avec quelles limites.
