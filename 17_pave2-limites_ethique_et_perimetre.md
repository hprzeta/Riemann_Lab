# Limites, éthique et périmètre CryptoZeta

CryptoZeta est défensif et pédagogique.

## Interdits dans le projet
- pas d'attaque de clés ;
- pas d'exploitation ;
- pas de contournement ;
- pas d'outils offensifs ;
- pas de prétention de preuve de RH.

## Autorisé
- documentation ;
- démonstrations jouet ;
- audit défensif ;
- hash/checksum ;
- recovery ;
- explications sur RSA, ECC, PQC et zêta.
