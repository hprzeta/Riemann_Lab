# Limites, conjectures, preuves Primalité

Riemann_Lab distingue toujours :

- calcul expérimental ;
- validation numérique ;
- visualisation ;
- conjecture ;
- preuve formelle.

Un calcul de zéros ou une reconstruction tronquée d'une formule explicite ne constitue pas une preuve de l'hypothèse de Riemann.
