La fonction $\theta(t)$ de Riemann-Siegel

Définition exacte, formule de Stirling, rôle dans la détection des zéros de $\zeta$ — animé et interactif.

Ce cours est le premier de la série. Dans le cours n°3 on verra que les zéros de $\zeta$ sur la droite critique sont exactement les changements de signe de $Z(t)$. Pour construire $Z(t)$, on a besoin de $\theta(t)$ : c'est l'objet de ce cours.

1. Définition exacte de $\theta(t)$

La fonction de phase de Riemann-Siegel $\theta(t)$ est définie par :

$$\theta(t) = \text{Im}\!\left[\ln\Gamma\!\left(\tfrac{1}{4}+\tfrac{it}{2}\right)\right] - \frac{t}{2}\ln\pi$$

C'est une fonction réelle et continue pour $t>0$. Elle mesure l'angle accumulé par la fonction zêta sur la droite critique. La branche du logarithme est choisie de manière à ce que $\theta(0) = 0$.

La définition via $\Gamma$ n'est pas commode pour le calcul numérique. On utilise l'approximation asymptotique ci-dessous.

2. Formule asymptotique — Stirling

Pour $t \geq 20$, l'approximation est précise à mieux que $10^{-9}$ :

$$\theta(t) \approx \frac{t}{2}\ln\frac{t}{2\pi} - \frac{t}{2} - \frac{\pi}{8} + \frac{1}{48t} + \frac{7}{5760\,t^3} - \frac{31}{80640\,t^5}$$

Le terme dominant est $\tfrac{t}{2}\ln\tfrac{t}{2\pi} - \tfrac{t}{2}$. Les corrections $-\tfrac{\pi}{8}$ et $\tfrac{1}{48t}$ viennent du développement de Stirling de $\ln\Gamma$. Croissance asymptotique : $\theta(t) \sim \tfrac{t}{2}\ln t$ quand $t\to+\infty$ : $\theta$ croît sans borne, mais lentement.

3. Équation fonctionnelle sur la droite critique

La factorisation de Hardy-Siegel relie $\zeta$ sur la droite critique à une fonction réelle :

$$\zeta\!\left(\tfrac{1}{2}+it\right) = e^{-i\theta(t)}\,Z(t) \qquad \text{avec } Z(t) \in \mathbb{R}$$

$\zeta(\tfrac{1}{2}+it)$ est un nombre complexe : il pointe dans une direction quelconque dans $\mathbb{C}$. En multipliant par $e^{-i\theta(t)}$, on le contra-rotationne exactement de la bonne phase, et le résultat $Z(t)$ atterrit sur l'axe réel. $\theta(t)$ est la phase intrinsèque de $\zeta$ sur la droite critique.

$Z(t)$ est calculé efficacement via la formule de Riemann-Siegel :

$$Z(t) = 2\sum_{n=1}^{N}\frac{\cos\!\left(\theta(t)-t\ln n\right)}{\sqrt{n}}+R(t), \qquad N=\left\lfloor\sqrt{\tfrac{t}{2\pi}}\right\rfloor$$

4. Rôle dans la détection des zéros

La factorisation donne immédiatement :

$$\zeta\!\left(\tfrac{1}{2}+it\right) = 0 \;\Longleftrightarrow\; Z(t) = 0$$

puisque $e^{-i\theta(t)}\neq 0$ pour tout $t\in\mathbb{R}$. Chercher les zéros de $\zeta$ sur la droite critique revient à chercher les racines réelles de $Z(t)$. On passe d'un problème complexe à une recherche de racines réelles classique. En pratique :

  • On balaye $t$ par pas adaptatif et on calcule $Z(t)$ (formule RS ou mpmath.siegelz)
  • Deux valeurs consécutives de signe opposé → changement de signe → zéro entre elles
  • Affinage avec la méthode Illinois (précision 35 décimales)

5. Connexion avec $N(T)$ — formule de Backlund

Notons $N(T)$ le nombre de zéros $\rho = \sigma + i\gamma$ avec $0 < \gamma \leq T$. La formule de Backlund (1918) :

$$N(T) = \frac{\theta(T)}{\pi} + 1 + S(T), \qquad S(T) = O(\log T)$$

En pratique $|S(T)| \leq 3$ pour tous les $T$ calculés. La formule de von Mangoldt donne l'approximation principale :

$$N(T) \approx \frac{T}{2\pi}\ln\frac{T}{2\pi e}$$

Test de Turing : si le nombre de changements de signe de $Z$ dans $[0,T]$ coïncide avec $\lfloor\tfrac{\theta(T)}{\pi}\rfloor+1$, il ne manque aucun zéro dans cet intervalle. Le projet Riemann_Lab applique ce test sur les 10 142 zéros calculés jusqu'à $T=10\,000$ — résultat : aucun manquant.
